This example demonstrates collapsible groups, including nested ones. Collapsing a group hides its members using the model-level [`hidden`](/docs/guides/conditional-visibility/) flag and shrinks the group to a header bar, while edges crossing the group boundary are temporarily rerouted to the group so external connections stay visible.

## Additional Explanation

### Key Concepts

- **Hiding with the `hidden` flag:** Collapsing a group sets [`hidden`](/docs/api/types/model/simplenode/#hidden) only on the group's **direct children** in one [`updateNodes`](/docs/api/services/ngdiagrammodelservice/#updatenodes) call. The effective-visibility cascade does the rest: descendants of a hidden child group are hidden automatically, and so is every edge touching a hidden node.
- **Nested collapse composes:** A nested group that was collapsed keeps its own children's `hidden` flags, so collapsing and expanding an outer group preserves the inner group's collapsed state — no bookkeeping of nested visibility is required.
- **Native interaction exclusion:** Hidden members are excluded from hit-testing, `selectAll`/box selection, `zoomToFit` bounds and the minimap by the library — no `pointer-events` or CSS visibility workarounds.
- **Boundary edge rerouting:** Edges with exactly one endpoint inside the collapsed group would disappear together with their hidden endpoint. The example redirects that endpoint to the group node for the duration of the collapse and restores it on expand. Each group touches only the endpoint on its own side, so sibling and nested groups can be collapsed and expanded in any order.
- **Group behavior:** The group template uses the [resize adornment](/docs/api/components/ngdiagramnoderesizeadornmentcomponent/), [`ngDiagramNodeSelected`](/docs/api/directives/ngdiagramnodeselecteddirective/) and [`ngDiagramGroupHighlighted`](/docs/api/directives/ngdiagramgrouphighlighteddirective/) — see the [Groups guide](/docs/guides/nodes/groups/). An expanded group can be resized, but not below the bounds of its visible children.
