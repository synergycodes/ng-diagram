The `NgDiagramPaletteItemPreviewComponent` defines the preview of a palette item shown while it is
dragged onto the canvas.

## Example usage
```html
<ng-diagram-palette-item-preview>
  <!-- Palette item content here -->
</ng-diagram-palette-item-preview>
```
