> **isDanglingEdge**(`edge`): `boolean`

Checks whether an edge is dangling — has at least one endpoint not connected
to a node. An edge with both endpoints free is a dual dangling edge.

## Parameters

### edge

[`Edge`](/docs/api/types/model/edge/)

## Returns

`boolean`
